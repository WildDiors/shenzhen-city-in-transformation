## 规格

- 历史照片：横向 3:2，建议 2400×1600，保留原始来源信息。
- 生成式场景：横向 16:9，建议 2400×1350，避免在图片内生成标题和 UI。
- 地标详情：4:3，建议 1600×1200。
- 地图图层：SVG 或透明 PNG，统一 viewBox 520×310。
- UI 纹理：可平铺 SVG，单张 512×512。
- 每张资产必须附带：来源/生成提示词、年代、地点、版权状态、替代文本。
