# Shenzhen: A City in Transformation

深圳城市历史地图是一个以时间、地标、城市边界和视觉档案为核心的互动叙事网站，记录深圳从改革开放初期到今天的城市演化。

## 第一版范围

- Timeline：1980 / 1992 / 2004 / 2010 / 2018 / 2024 六个历史节点，切换时同步更新场景、文案、统计和 Compare 内容。
- Landmark：按制度实验、跨境连接、城市天际线、产业网络、公共界面、未来接口筛选，点击地标显示历史解释。
- Compare：可拖动中线，实时改变两个时代的视觉占比，并随 Timeline 更新内容。
- City Footprint：水岸、铁路、轨道、创新、绿色基础设施、深圳河六个图层可开关，地图会真实显隐对应图层。
- Placeholder visual system：以占位城市影像、地图线稿和可替换视觉槽位承载 P0 交互，后续按 docs/asset-plan-96.md 替换为真实历史照片和 AI 视觉。

## 本地预览

直接打开 `dist/index.html` 即可预览。网站为无依赖静态版本，可部署到任何静态托管平台。
